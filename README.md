# POKECARD（はるか専用デジタルポイントカード） Ver1.0

ポケモンカードの抽選当選時にスタンプを1つ貯めて、特別な特典（映画・焼肉・水族館・ディズニーシーなど）と交換できる、はるか専用のWeb/PWAスタンプカードアプリです。

---

## ✨ 主な機能 & 特徴

1. **デザインカンプ完全再現の上品なUI**
   - 白・アイボリー・ベージュ・ゴールドを基調とした上質感あるデザイン
   - モンスターボール風のオリジナル赤色スタンプ（ランダムな手押し角度でリアルさを演出）
   - スタンプカード（2行×5列＝10マス）
   - 「次のリワード」カード（イーブイアイコン、必要残数自動計算）

2. **スタンプ獲得演出（最重要機能）**
   - QRコードをスマホの標準カメラで読み取るか、アプリ内カメラでスキャンすると自動起動
   - 全画面でおしゃれな「*Congratulations!*」「スタンプGET！」画面を表示
   - 赤いスタンプが「ポンッ！」と打刻されるアニメーション + 紙吹雪（Confetti）+ 効果音
   - 約1.5秒後に自動でホーム画面へ戻り、カードにスタンプが追加されます

3. **リワード交換システム**
   - 映画デート（3個）、焼肉デート（5個）、水族館デート（7個）、ディズニーシー（10個）
   - 達成状況に合わせてボタンが活性化
   - 交換確認ダイアログ ➔ スタンプ消費 ➔ 履歴自動保存 ➔ 完了演出

4. **履歴 & パートナー支援ツール**
   - ポイント獲得・特典交換の日時履歴
   - パートナー用「当選QRコード発行」機能（相手のスマホで読み取らせるQRを即時表示）
   - LINEやメッセージで送れる「当選リンクコピー」機能
   - テスト用スタンプ増減・初期化リセット機能

5. **PWA対応（完全無料・サーバー不要）**
   - iPhoneのSafariから「ホーム画面に追加」するだけで、ネイティブアプリのように全画面で起動
   - Service Workerによるオフラインキャッシュ対応
   - GitHub PagesにリポジトリをPushするだけで世界中に完全無料で公開可能

## 🚀 GitHub Pages へのデプロイ方法

1. GitHubで新規リポジトリ（例: `pokecard`）を作成します。
2. このフォルダの内容をリポジトリへコミット＆プッシュします。
   ```bash
   git init
   git add .
   git commit -m "Initial commit of POKECARD v1.0"
   git branch -M main
   git remote add origin https://github.com/<あなたのユーザー名>/pokecard.git
   git push -u origin main
   ```
3. GitHubリポジトリの **Settings** > **Pages** に移動します。
4. **Build and deployment** の Source で **Deploy from a branch** を選択し、`main` ブランチの `/ (root)` を指定して **Save** します。
5. 数十秒で `https://<あなたのユーザー名>.github.io/pokecard/` に公開されます！

## 📱 iPhone（はるかさん側）での使い方

1. 公開されたURLをSafariで開きます。
2. 画面下部の「共有ボタン（四角から上矢印）」をタップします。
3. **「ホーム画面に追加」** をタップすると、ホーム画面に「POKECARD」のモンスターボールアイコンが追加されます。
4. ポケモンカードに当選した際は、パートナーが提示するQRコードを標準カメラで読み取るだけで自動的にスタンプが付与されます！
